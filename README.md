# 💰 Financial Money Flow – Expense & Income Tracker

A responsive web application for tracking personal income and expenses. Built using **HTML, CSS, and Vanilla JavaScript**, with **LocalStorage persistence** for saving data in the browser.

## 📌 Features

### 💵 Finance Management
- Add Income and Expense entries
- Edit existing transactions
- Delete transactions
- Automatic balance calculation

### 📊 Dashboard Summary
- Total Income
- Total Expense
- Net Balance
- Number of Transactions

### 🔍 Smart Features
- Search transactions by keyword (description, category, date, amount)
- Filter by:
  - All Entries
  - Income only
  - Expense only

### 💾 Data Persistence
- Uses LocalStorage (data remains after refresh)

### 📱 Responsive Design
- Works on:
  - Desktop
  - Tablet
  - Mobile (basic support)

## 🛠️ Tech Stack
